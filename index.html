Publications · 5편 (제1저자 2편)

  1. 01 학술대회 1저자 2026.08

    산업안전 모니터링을 위한 MobileCLIP-CoOp 모델의 Edge AI 적용에 관한 연구

    한국전기전자학회 하계학술대회

    산업 현장의 이상 상황은 사고 특성상 학습 데이터를 충분히 모으기 어렵습니다. 이 연구는 경량 비전-언어 모델인 MobileCLIP에 프롬프트 학습 기법 CoOp을 적용해, 클래스당 8장의 이미지만으로 분류기를 학습시키는 방식을 제안했습니다.

    Jetson 계열 엣지 보드에서 ONNX 변환과 TensorRT FP16 최적화를 거쳐 추론 지연을 19.8ms까지 낮췄고, 8-shot 조건에서 93.3%의 분류 정확도를 확보했습니다. Zero-shot 대비 최대 22.0%p 개선된 결과입니다.

    • MobileCLIP
    • CoOp
    • Few-shot Learning
    • TensorRT
  2. 02 학술대회 1저자 2025.11

    임베디드 시스템 환경에서의 CCTV 기반 실시간 작업자 안전 모니터링 알고리즘에 관한 연구

    한국지능시스템학회 추계학술대회

    현장에 이미 설치된 CCTV 영상을 그대로 활용해, 별도 장비 증설 없이 작업자 안전을 감시하는 알고리즘을 제안했습니다. 객체 탐지 결과를 작업 구역 정보와 결합해 위험 상황을 판정하는 구조입니다.

    연산 자원이 제한된 Jetson Nano 환경에서 실시간성을 확보하는 데 초점을 맞췄고, 모델 경량화와 전처리 단계 최적화를 통해 15 FPS의 처리 속도를 달성했습니다.

    • CCTV
    • Object Detection
    • Jetson Nano
    • 실시간 처리
  3. 03 등재학술지 2저자 2026.03

    임베디드 환경에서 딥러닝 기반 전염병 확산 방지 시스템

    스마트미디어저널 제15권 3호

    영상과 음향을 함께 사용해 전염병 확산 위험 요소를 감지하는 시스템을 다룬 연구입니다. 영상에서는 인원 밀집과 마스크 착용 여부 등을, 음향에서는 기침 등 이상 신호를 판별하는 구조로 구성했습니다.

    전체 파이프라인을 임베디드 보드에서 동작시키는 것을 전제로 설계해, 모델 크기와 처리 순서를 조정하며 제한된 자원 안에서 두 가지 신호를 함께 다루는 방법을 검증했습니다.

    • Vision
    • Audio
    • Embedded
  4. 04 학술대회 2저자 2025.11

    열화상 기반 실시간 산업현장 위험 모니터링에 관한 연구

Engineering Detail · 3건

  1. 01 Edge AI 2026

    Edge AI 기반 작업장·작업자 이상 상황 탐지 시스템

    모델 학습 · 엣지 최적화 · 구동부 제어

    MobileCLIP에 CoOp을 적용한 Few-shot 분류 모델을 구현하고, 탐지 결과를 Grad-CAM으로 시각화해 이상이 발생한 위치를 산출했습니다. 산출된 좌표는 PID 제어와 RS485 통신을 통해 Pan/Tilt 구동부로 전달되어 카메라가 대상을 따라가도록 연결했습니다.

    모델 정확도뿐 아니라 파이프라인 전체의 지연을 함께 다뤘습니다. ONNX 변환과 TensorRT FP16 최적화, 카메라 입력 단계 개선을 통해 추론 지연을 94.6ms에서 19.8ms로 단축해 약 4.8배의 속도 향상을 얻었습니다.

    • MobileCLIP
    • CoOp
    • Grad-CAM
    • TensorRT
    • Jetson Orin
    • PID · RS485
  2. 02 AIoT 2024 — 2026

    스마트 산업 현장 안전 모니터링 플랫폼

    센서 수집 · 시계열 분석 · 시스템 통합

    온·습도, CO, CO₂, TVOC, 미세먼지, CT 센서와 음향 센서, RGB·열화상 카메라를 결합한 통합 안전관리 시스템입니다. Arduino Mega2560을 기반으로 다중 센서 데이터를 수집하고, 센서마다 노이즈 특성이 달라 필터 조합을 개별적으로 설계했습니다.

    수집된 데이터는 시계열 예측과 영상 분석을 거쳐 위험도를 판정하고, 경고 발생과 구동기 제어로 이어집니다. 결과는 서버를 통해 Web/App으로 전달되어 현장 밖에서도 상태를 확인할 수 있도록 구성했습니다.

    • YOLO
    • 다중 센서
    • LSTM
    • Arduino
    • Web / App
  3. 03 Multimodal 2026

    영상·음향 복합 신호 기반 실시간 위험 감지

    다중 객체 추적 · 음향 분류 · 병목 최적화

    열화상과 RGB 영상의 객체 탐지 결과에 음향 분석을 결합해 위험 상황을 판별했습니다. YOLOv6n과 DeepSORT 기반의 다중 객체 추적을 Raspberry Pi 4B 환경에 통합했고, 파이프라인 단계별 병목을 측정해 추적 속도를 1 FPS에서 8 FPS까지 개선했습니다.

    음향 신호에는 MFCC 변환 후 CNN 분류기를 적용해 폭발음·비명음·배경음을 구분했습니다. 데이터 증강으로 학습 데이터의 편중을 줄여 최대 99.7%의 분류 정확도를 확인했습니다.

    • YOLOv6n
    • DeepSORT
    • MFCC · CNN
    • Raspberry Pi 4B
